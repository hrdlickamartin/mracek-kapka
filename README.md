# Mráček Kapáček

Hra pro děti 3–5 let: malý mráček Kapáček nabírá vodu, zalévá rostlinky a krajina rozkvétá. Ovládá se jedním prstem, nedá se prohrát a nemá skóre, časové limity, reklamy ani nákupy.

Hrát na webu: https://hrdlickamartin.github.io/mracek-kapka/

- `docs/` – Game Art Bible a UI Style Guide (PDF)
- `npm install`, pak `npm run web` (Expo SDK 58)
- `npm run check` – typy, lint, testy enginu a progrese, české glyfy fontů
